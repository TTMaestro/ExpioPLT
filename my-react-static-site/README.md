# My React Static Site

Это статический сайт, созданный с использованием React. Он включает в себя основные файлы и структуру для разработки приложения.

## Структура проекта

```
my-react-static-site
├── public
│   ├── index.html
├── src
│   ├── components
│   │   └── App.js
│   ├── index.js
│   └── styles
│       └── App.css
├── package.json
└── README.md
```

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <URL_репозитория>
   ```
2. Перейдите в директорию проекта:
   ```
   cd my-react-static-site
   ```
3. Установите зависимости:
   ```
   npm install
   ```

## Запуск приложения

Для запуска приложения используйте команду:
```
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.
